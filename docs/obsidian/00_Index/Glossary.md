# Glossary

- **MVP**: Minimum Viable Product.
- **Provider**: AI backend endpoint (remote or local).
- **OpenAI-compatible**: API shape compatible with `/chat/completions` and SSE.
- **SSE**: Server-Sent Events for progressive streaming.
- **Local-first**: Local persistence and operation by default.
- **Keychain**: macOS secure secret storage.
- **MOC**: Map of Content note used as navigation hub.
