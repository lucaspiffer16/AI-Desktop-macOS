## Naming and Linking Rules

- One concept per note whenever practical.
- Internal links use wiki links: `[[Note Name]]`.
- Use section links for precision: `[[MVP_Scope_In#Included in MVP]]`.
- Keep each note connected to at least one MOC and one related technical or product note.
