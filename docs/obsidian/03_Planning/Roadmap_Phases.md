# Roadmap Phases

- **Phase 1**: provider management, streaming chat, local storage, privacy mode.
- **Phase 2**: prompt templates, workspace profiles, export/import, improved search.
- **Phase 3**: file context, RAG, tools, agents, plugin system.

## Gate to Move Beyond Phase 1

- MVP AC coverage is stable.
- Core runtime risks have mitigations and owners.
- Architecture contracts are respected in implementation.
