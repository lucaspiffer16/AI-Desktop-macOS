# Product Principles

- Native First
- Local First
- Provider Agnostic
- Privacy by Design
- Extensible Architecture

## Principle to Design Translation

- Native First -> prioritize platform conventions, shortcuts, and responsiveness.
- Local First -> default to local persistence and local provider compatibility.
- Provider Agnostic -> enforce abstraction contracts and capability detection.
- Privacy by Design -> include privacy modes and explicit non-guarantee messaging.
- Extensible Architecture -> isolate modules and keep provider layer replaceable.
