# Personas

- **Developer**: fast local model access, flexible APIs, privacy while sharing screen.
- **Technical Professional**: reliability, speed, minimal setup.
- **Privacy-Oriented User**: strong local support, reduced cloud dependency.

## Operational Implications

- Developer persona drives provider configurability and diagnostics depth.
- Technical professional drives stable defaults and predictable UX states.
- Privacy-oriented persona drives shortcut immediacy and explicit limitations copy.

## Risks if Ignored

- Over-complex setup hurts adoption.
- Weak privacy communication creates trust issues.
- Slow streaming or unstable sessions reduce productivity value.
