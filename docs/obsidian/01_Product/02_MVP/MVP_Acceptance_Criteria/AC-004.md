# AC-004

Given a saved conversation, when app restarts, then history persists locally.

## Scenarios

- Happy path: restart app and recover conversation list and message ordering.
- Error path: corrupted entry is isolated without blocking remaining history.
- Boundary: large history loads incrementally without full-memory hydration.

## Measurable Checks

- Persisted conversation metadata is available on startup without remote dependency.
- Message order remains stable by timestamp and sequence rules.

## Verification Notes

- Validate cold start with multiple conversations and mixed message sizes.
