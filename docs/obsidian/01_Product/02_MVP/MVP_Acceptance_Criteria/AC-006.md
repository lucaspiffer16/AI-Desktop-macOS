# AC-006

Given privacy mode disabled, when user exits privacy mode, conversation state is restored.

## Scenarios

- Happy path: app returns to previous conversation, scroll region, and composer context.
- Error path: previous view no longer available, app restores nearest safe conversation state.
- Boundary: exit during active streaming resumes coherent UI without hidden artifacts.

## Measurable Checks

- Restore occurs within 500 ms after privacy mode exit in normal conditions.
- No data loss in unsent draft text due to privacy toggle.

## Verification Notes

- Validate restore behavior for minimized, hidden, and blurred entry states.
