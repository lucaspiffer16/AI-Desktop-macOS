# AC-005

Given privacy mode enabled, when shortcut is activated, content is hidden or blurred immediately.

## Scenarios

- Happy path: shortcut activates configured privacy mode instantly.
- Error path: preferred mode unavailable, fallback hide mode is applied.
- Boundary: rapid toggle actions do not leave mixed or stale visual state.

## Measurable Checks

- Visual privacy effect starts within 300 ms after shortcut trigger.
- No prior message content remains readable once privacy mode is active.

## Verification Notes

- Validate behavior across blur, compact, and hide modes.
