# AC-003

Given an active conversation, when user sends a message, then assistant response streams progressively.

## Scenarios

- Happy path: first token appears progressively and message completes.
- Error path: stream interruption preserves partial content and shows retry affordance.
- Boundary: user cancellation stops stream cleanly and keeps conversation coherent.

## Measurable Checks

- First visible stream update should occur within 3 seconds in normal network conditions.
- UI remains responsive during streaming and cancellation actions.

## Verification Notes

- Test long responses, cancellation, and provider-side stream errors.
