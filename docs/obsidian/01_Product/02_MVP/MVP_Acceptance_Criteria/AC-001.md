# AC-001

Given a valid OpenAI-compatible endpoint, when the user tests the provider, then connectivity validates successfully.

## Scenarios

- Happy path: valid base URL + valid key + expected schema returns success and model list.
- Error path: invalid key returns auth error with actionable guidance.
- Error path: timeout returns retry option and no secret leakage.
- Boundary: custom OpenAI-compatible path validates when endpoint differs from default host.

## Measurable Checks

- Connection test feedback appears within 10 seconds for reachable endpoints.
- No API key value is shown in logs or visible debug text.

## Verification Notes

- Validate with at least one remote provider and one local compatible endpoint.
