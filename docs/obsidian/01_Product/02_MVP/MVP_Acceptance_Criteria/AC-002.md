# AC-002

Given valid credentials, when the user saves a provider, then API key is stored in Keychain.

## Scenarios

- Happy path: save provider and retrieve key through Keychain-backed path only.
- Error path: Keychain write denied and user receives recoverable error.
- Boundary: updating provider rotates stored key without leaving stale plain-text copies.

## Measurable Checks

- No persistence model includes raw API key fields.
- App logs and crash diagnostics do not include key material.

## Verification Notes

- Inspect persistence schema and runtime logging during provider save/update flows.
