# Accessibility

- VoiceOver compatibility.
- Keyboard navigation.
- Scalable text sizes.

## Accessibility Baselines

- Interactive elements expose semantic labels.
- Keyboard-only operation supports main flows and privacy toggle.
- Streaming updates should remain understandable for assistive tech users.

## Validation Focus

- Verify focus order in settings, sidebar, composer, and privacy controls.
- Verify text scaling does not hide critical controls.
