# Capture Restriction Attempt

The app may attempt native macOS window-sharing restrictions to reduce capture visibility.

This is best effort only and must not be communicated as guaranteed invisibility.

## Communication Rule

- Product copy must say privacy assistance, not capture prevention.

## Validation Focus

- Verify expected behavior on native window-sharing flows.
- Document known limitations for third-party capture tools.
