# Technical Overview

- Native Swift and SwiftUI.
- MVVM architecture.
- Service-oriented infrastructure.
- Provider abstraction layer.
- SwiftData for MVP persistence.

The architecture is optimized for fast local-first delivery while preserving extension points for future providers, advanced retrieval workflows, and optional sync layers.
